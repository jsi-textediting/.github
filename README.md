# JSi Text Editing

Lightweight, hackable, and high-performance text editing tools, runtimes, and extensions.

## Projects

* **[lite-xl](https://github.com/jsi-textediting/lite-xl)** — A lightweight, fast text editor written in Lua with a native C backend. Features native performance optimizations and built-in [`thither`](https://github.com/jsi-textediting/lite-xl/tree/main/thither) remote editing over SSH without requiring background daemons.
* **[lite-xl-plugins](https://github.com/jsi-textediting/lite-xl-plugins)** — A curated collection of plugins for Lite XL, featuring declarative management via [`use_package`](https://github.com/jsi-textediting/lite-xl-plugins/tree/main/plugins/use_package), remote editing integration, and ergonomic navigation and search tools (Avy, Which-Key, Isearch, Ripgrep, and more).
